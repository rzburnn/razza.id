# razza.id
MEN RUN adalah game endless runner 2D bergaya pixel art yang mengangkat kontras suasana jalanan urban. Pemain berperan sebagai pelari yang harus bertahan hidup melewati berbagai rintangan khas jalanan—seperti tumpukan ban, pembatas rantai, dan tiang listrik—sambil mengumpulkan koin tengkorak untuk membangun combo skor.
